# Trabajo académico: Física Computacional

Colección de laboratorios de Física Computacional de Ingeniería de Sistemas en la UNSA. Se conserva la información académica original al final.

## Capacidades y organización

Simulación y análisis numérico, visualización y documentación de fenómenos físicos mediante herramientas computacionales.

Las carpetas `lab01` a `lab10` agrupan los ejercicios y recursos. Algunos laboratorios incluyen sus enunciados PDF y otros contienen ejemplos y código de herramientas externas.

## Ejecución

Revisar el enunciado y las importaciones del ejercicio elegido. Cada laboratorio tiene sus propias dependencias; no hay un único entorno documentado para toda la colección. Como ejemplo, desde la raíz:

```bash
python lab01/lab01.py
```

Instalar previamente las dependencias que requiera el script y ajustar los recursos de entrada del ejercicio.

## Atribución y alcance

Los ejemplos y componentes externos conservan sus archivos de licencia y documentación. Su inclusión no implica autoría propia. La colección presenta ejercicios académicos y no resultados científicos validados en esta actualización.

### Descripción
En este laboratorio exploramos conceptos avanzados de física utilizando herramientas computacionales. Desde la simulación de campos magnéticos hasta la modelización de fenómenos físicos complejos, nuestro objetivo es fusionar la teoría con la práctica informática.

### Contenido del Repositorio
- **Códigos Python:** Encuentra aquí scripts y programas desarrollados para simular y analizar fenómenos físicos.
- **Documentación:** Documentos, informes y análisis resultantes de nuestras investigaciones y experimentos.
